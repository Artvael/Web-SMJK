# 🎓 FORM 6 @ SMJK CHUNG HWA, KELANTAN (S.M.C.H. 1918)
### Official Student Portal & PETINAM Student Council

A high-energy, interactive **Figma Neobrutalist Web Application** built for the Form 6 community and PETINAM Student Council of SMJK Chung Hwa, Kota Bharu, Kelantan.

---

## 🌟 Key Features

- **🎨 Figma Neobrutalist Design System:**
  - High-contrast 2.5px–4px black borders, hard drop-shadows, pastel pop highlights, and dot-matrix canvas.
- **⚡ Staggered Drawer Navigation:**
  - Multi-layer animated drawer powered by GSAP with custom `Menu +` and `Close ✕` toggle actions.
- **🚀 Interactive Figma Tool Dock & Scroll Progress Bar:**
  - Smooth spring scroll progress indicator at the top edge.
  - Interactive Figma dock with sliding indicator between Select Tool `(V)` and Hand Tool `(H)`.
- **📌 Interactive Student Voice Sticky Board (`VoiceBoard`):**
  - Live bulletin board with category dropdown (Suggestion, Problem, Appreciation, Request).
  - Real-time note pinning, realistic washi-tape memo styling, and persistent like reactions.
- **📚 Academic Hub & Past-Year Binders:**
  - STPM Sem 1 exam countdown timer, subject binders (Pengajian Am, Biology, Chemistry, Mathematics, MUET).
- **📅 Form 6 Master Calendar:**
  - Interactive desk planner with color-coded exam and academic event filters.
- **👑 Authentic PETINAM Student Council:**
  - Interactive committee notebook featuring President Vannie Liew, executive members, and 8 portfolio exco teams.
- **🎓 University & Alumni Corner:**
  - Guide to top Malaysian public universities (UM, USM, UKM, UPM) and scholarship portals.
- **🎯 Dynamic User Cursor with Badge:**
  - Custom fluid cursor with interactive customizer.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (Neobrutalism Design Tokens)
- **Animations:** Framer Motion + GSAP
- **Icons:** Lucide React
- **Celebrations:** Canvas Confetti
- **Linting:** Oxlint
- **Backend / Storage:** Supabase Client & LocalStorage sync

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Artvael/Web-SMJK.git
cd Web-SMJK
```

### 2. Install dependencies
```bash
corepack pnpm install
# or: npm install / yarn / bun
```

### 3. Start development server
```bash
corepack pnpm run dev
```

### 4. Build for production
```bash
corepack pnpm run build
```
